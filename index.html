01

하네스
엔지니어링이란?

말의 고삐나 안장을 뜻하는
"하네스"로 안전을 설계하다

하네스(Harness)란 말의 고삐나 안장을 의미합니다.

엔지니어링은 AI 코딩 에이전트가 안전하고 예측 가능하게 일할 수 있도록 주변 환경을 설계하는 기술입니다.

단순히 더 좋은 모델을 기다리는 것이 아니라, 기존 모델을 둘러싼 시스템을 개선하여 성능을 2배로 높이는 기술입니다.

02

왜 지금
하네스 엔지니어링인가?

AI 모델이 좋아도
제어 시스템 없이는 실수를 반복한다

AI 모델(Claude, GPT, Codex)의 성능이 좋아도, 제어 시스템 없이는 돌발 행동이나 실수를 반복합니다.

"에이전트가 실수할 때마다, 그 실수가 다시 발생하지 않도록 시스템을 고쳐라"

AI에게 1000페이지 매뉴얼 대신, 구조화된 지도를 주어 오류를 원천 차단합니다.

03

하네스 엔지니어링
= Agent

모델(말) + 하네스(고삐) =
완벽한 에이전트

모델(AI): 지능과 판단력

하네스(구조): 컨텍스트, 규칙, 도구, 피드백 루프

모델 자체를 바꾸지 않아도 하네스 설계만으로 AI 코딩 성능을 비약적으로 상승시킬 수 있습니다.

04

핵심 구성
3가지

도구, 환경, 제약을
한자리에서 관리

컨텍스트: MCP 등을 통한 필요한 정보의 실시간 전달

도구: AI가 직접 코드를 수정, 테스트, 반영하도록 하는 실행 루프

제약: 시스템 프롬프트 및 AGENTS.md를 통해 자유 행동 제한

05

개발 방법론
Humans Steer, Agents Execute

사람은 감독자,
AI는 실행자

사람의 역할: 코딩이 아닌 환경 설계자(감독자)로 전환

원칙: 사람이 방향을 설정하면, AI 에이전트가 코드를 작성하고 테스트합니다

AGENTS.md 파일을 통해 에이전트에게 컨벤션, 규칙, 작업 방식을 기계적으로 명시합니다

06

3단계 개발
방법론

정보 → 실행 → 피드백
완전한 루프 시스템

1단계: docs 폴더에 에이전트가 읽기 쉬운 구조화된 지식 배치

2단계: 커스텀 린터와 테스트 케이스로 자동화된 검증 게이트 구축

3단계: AI가 실수를 하면 환경을 고쳐 다시는 같은 실수를 안 하도록 자동화된 피드백 루프 적용

07

실패를 막는
자동 교정

랄프 윅검 루프:
실수를 자동 교정하는 시스템

에이전트가 작성한 코드에 에러가 발생하면, AI가 자동으로 재작업하여 교정본을 생성합니다.

자동으로 코드를 수정하고, 다시 검토하고, 테스트를 통과할 때까지 반복합니다.

이름 유래: Simpsons의 랄프 윅검 - 매번 실수하지만 사랑스러운 캐릭터처럼, AI도 반복적으로 교정됩니다

08

하네스 환경
시각화

실제 운영에서
어떻게 활용하는가?

Codebase: Cursor Rules를 활용한 규칙 버전 관리

DevOps: CI/CD와 결합하여 에이전트가 Pull Request를 자동으로 생성 및 통과

Structure: 모노레포를 채택하여 AI가 전체 시스템 구조를 파악하게 합니다

09

성공 사례
Stripe의 1,300개 AI PR

체계적인 시스템이
대규모 작업을 가능하게 한다

Stripe는 하네스 엔지니어링을 통해 주당 1,300개의 AI 생성 PR을 안정적으로 처리합니다.

단일 AI 모델의 성능보다, 체계적인 시스템 환경 설계가 대규모 작업에 더 유리함을 증명했습니다.
